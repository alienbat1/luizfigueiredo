# Site do Luiz Figueiredo

Site estático (HTML/CSS/JS). Por enquanto só a Home (`index.html`).

## Publicar no GitHub Pages
1. Crie um repositório no GitHub (ex.: `luizfigueiredo`).
2. Envie todo o conteúdo desta pasta (Add file → Upload files), incluindo `.nojekyll`.
3. Settings → Pages → Source: "Deploy from a branch" → `main` / root → Save.
4. Em ~1 min o site abre em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.

## Para completar
Procure por "A COMPLETAR" no `index.html`: capas dos postcards, credenciais, contatos (WhatsApp, Instagram, e-mail, YouTube), og:url/og:image.
